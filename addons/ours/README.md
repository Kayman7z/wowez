# Наши аддоны

Перетащите сюда zip-архив аддона (кнопка «Add file → Upload files» на GitHub) и нажмите «Commit changes».
Сайт сам прочитает название, версию, автора и описание из файла .toc внутри архива.

Чтобы добавить русское описание или скриншот, создайте рядом файл с тем же именем и расширением .json
(проще всего через форму «Добавить аддон» на странице «Аддоны» сайта).
